## What is working

The supported operator flow is:

```text
target validate
campaign validate
campaign plan (non-executing)
run with explicit kill-switch snapshot
        ↓
Target Gate + budgets
        ↓
HTTP_HEAD_STATUS
        ↓
PASS / FAIL
        ↓
sealed evidence
        ↓
report.json + report.txt + run.json + SHA256SUMS
```

There is no unrestricted arbitrary-target scanner command.

## Deliberately unarmed

v0.1.0 does not claim or provide signed target/campaign authorization, authentication/session testing, authorization/API campaigns, hostname/DNS execution, redirect following, scheduled continuous assurance, production Command Center authorization, confidential durable evidence storage, digital signer identity for evidence, or non-Linux-x86_64 prebuilt binaries.
